Footnotes:

1. Owned (library) albums only
2. "Random" button — picks a random vibe seed
3. Library-source artists only
4. Unowned albums only (with downloads enabled)
5. Discovery artists or artists with available (unowned) albums
6. Playlist owner only

The notable "silent" limit is the 100-track playback queue persistence — if a user has more than 100 tracks queued and refreshes the page, only
the first 100 survive. Playlists and liked tracks are effectively unbounded.
