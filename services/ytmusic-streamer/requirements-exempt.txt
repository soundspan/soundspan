# DELIBERATELY EXEMPT from hash-locking (roadmap F38/F50 carve-out).
#
# yt-dlp and ytmusicapi track YouTube's frequently-changing internals. A
# breakage (e.g. the android-client format regression) must be fixable with a
# same-day floor bump and rebuild; hash-pinning them would force a full lock
# regeneration on every YouTube break. They are therefore installed as loose
# floors, in a plain `pip install` AFTER the hash-locked requirements.lock.
#
# The `default` extra's stable dependencies (brotli, certifi, mutagen,
# pycryptodomex, requests, urllib3, websockets) are all pinned+hashed in
# requirements.lock, so the only dists that float at build time are yt-dlp,
# ytmusicapi, and yt-dlp-ejs. yt-dlp-ejs must float because each yt-dlp
# release pins it exactly (==) and a same-day yt-dlp floor bump has to be able
# to pull the matching yt-dlp-ejs without a lock regeneration.
#
# Floors here must match services/ytmusic-streamer/requirements.txt.
yt-dlp[default]>=2026.8.19
ytmusicapi>=1.12.2
